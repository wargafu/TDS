# Support du TDGS

## Trouver de l’aide

| Besoin                      | Canal recommandé                       |
| --------------------------- | -------------------------------------- |
| Question d’utilisation      | Discussion publique du dépôt           |
| Bug reproductible           | Issue avec reproduction minimale       |
| Proposition                 | Issue de proposition/RFC               |
| Vulnérabilité               | Canal privé décrit dans `SECURITY.md`  |
| Harcèlement                 | Canal confidentiel du Code de conduite |
| Validation institutionnelle | Autorité compétente, à désigner        |

## Informations à fournir

- version TDGS ;
- navigateur, système et framework ;
- langue et direction LTR/RTL ;
- code minimal ;
- résultat attendu et résultat obtenu ;
- impact accessibilité ou sécurité ;
- capture sans donnée personnelle, si utile.

## Limites

Le support communautaire ne constitue pas une homologation d’un service, un audit juridique, un audit de sécurité ou un audit complet d’accessibilité.
