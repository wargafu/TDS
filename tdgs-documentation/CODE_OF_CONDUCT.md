# Code de conduite du TDGS

## Notre engagement

Nous voulons une communauté respectueuse, accueillante et sûre, indépendamment du handicap, de l’âge, du genre, de la langue, de l’origine, de la religion, du niveau d’expérience ou du statut professionnel.

## Comportements attendus

- critiquer les idées, jamais les personnes ;
- communiquer clairement et avec respect ;
- accueillir les questions des débutants ;
- reconnaître les erreurs et les corriger ;
- protéger les informations personnelles ;
- considérer les besoins des usagers francophones, arabophones et handicapés.

## Comportements interdits

Harcèlement, discrimination, intimidation, insultes, menaces, divulgation de données personnelles, contenu haineux, sollicitations commerciales répétées et perturbation volontaire du projet.

## Signalement

Les coordonnées confidentielles de signalement doivent être renseignées par les mainteneurs avant publication. Ne pas signaler une vulnérabilité de sécurité dans une issue publique : consulter `SECURITY.md`.

## Application

Les mainteneurs peuvent avertir, masquer un contenu, suspendre ou exclure un participant. Les décisions doivent être proportionnées, documentées et permettre un recours lorsque cela est approprié.
