# @tdgs/tokens

Ce dossier est réservé à une éventuelle extraction future des tokens. Les tokens
maintenus et distribués aujourd’hui font partie de `@tdgs/core` :

```ts
import { color, spacing, typography } from '@tdgs/core/tokens';
```

Le package reste privé tant qu’une extraction ne fournit pas une API et une
version distinctes documentées.
