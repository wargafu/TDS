Le composant Étapes indique la position de l'usager dans une démarche. Il distingue les étapes
terminées, courante, à venir et en erreur sans imposer de logique de navigation.

## Do / Don't

<div class="tds-do-dont">
  <div class="tds-do-dont__card tds-do-dont__card--do">
    <div class="tds-do-dont__heading">✓ Faire</div>
    <ul>
      <li>Marquer une seule étape avec `aria-current="step"`</li>
      <li>Conserver des libellés courts et compréhensibles sur mobile</li>
      <li>Afficher l'état avec un libellé, pas seulement avec une couleur</li>
    </ul>
  </div>
  <div class="tds-do-dont__card tds-do-dont__card--dont">
    <div class="tds-do-dont__heading">✗ Éviter</div>
    <ul>
      <li>Rendre les étapes cliquables si aucune navigation n'est disponible</li>
      <li>Utiliser les étapes pour des vues alternatives (préférer Tabs)</li>
      <li>Masquer l'étape courante aux lecteurs d'écran</li>
    </ul>
  </div>
</div>

<TabItem label="Accessibilité">

<Aside type="tip" title="Règles critiques">
  - Utiliser un `nav` avec un nom accessible
  <br />
  - Marquer une seule étape avec `aria-current="step"`
  <br />
  - Ne rendre les étapes cliquables que si une navigation est réellement disponible
  <br />
  - Décrire l'état avec du texte et non avec la seule couleur
  <br />- Conserver une version lisible sur mobile et en RTL
</Aside>
