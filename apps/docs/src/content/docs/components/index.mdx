Le catalogue comprend **35 familles de composants UI**, complétées par l'utilitaire `Icon`. Le socle
CSS reste indépendant des frameworks : les bindings React et Vue réutilisent les mêmes tokens et les
mêmes classes `tds-*`.

<Aside type="tip" title="Comment lire une fiche composant">
  Chaque fiche documente l'intention, les variantes, les états, une démonstration basée sur le CSS
  buildé, les exemples HTML/React/Vue et les exigences d'accessibilité. Utilisez le terrain de jeu
  pour vérifier rapidement le rendu des composants dans les thèmes TDGS.
</Aside>
