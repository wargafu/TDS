<Tabs>
<TabItem label="Présentation">

Le `Tag` représente une catégorie, un filtre ou un état court. Il est distinct du `Badge` : le tag
peut être retiré dans une sélection, tandis que le badge est principalement un indicateur de statut.

Variantes : `default`, `info`, `success`, `warning`, `danger`. Tailles : `sm` et `md`.

</TabItem>
<TabItem label="Démo">

<TabItem label="Accessibilité">

<Aside type="tip" title="Le texte fait foi">
  - Ne communiquez jamais un état par la couleur ou le point seul : gardez un texte visible. - Un
  tag supprimable doit fournir un bouton avec un nom accessible et une cible tactile suffisante. -
  N'utilisez pas un tag comme bouton de navigation ; utilisez `Link` ou `Tile`.
</Aside>
