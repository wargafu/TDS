Le composant Recherche associe un champ `searchbox` natif à un formulaire. Il reste utilisable
avec un clavier, un lecteur d'écran et un navigateur sans JavaScript.

## Do / Don't

<div class="tds-do-dont">
  <div class="tds-do-dont__card tds-do-dont__card--do">
    <div class="tds-do-dont__heading">✓ Faire</div>
    <ul>
      <li>Conserver un label associé au champ</li>
      <li>Utiliser un bouton de soumission explicite</li>
      <li>Afficher un exemple dans le placeholder sans remplacer le label</li>
    </ul>
  </div>
  <div class="tds-do-dont__card tds-do-dont__card--dont">
    <div class="tds-do-dont__heading">✗ Éviter</div>
    <ul>
      <li>Déclencher une recherche uniquement avec une icône sans nom accessible</li>
      <li>Masquer les résultats sans les annoncer</li>
      <li>Utiliser le placeholder comme seul libellé</li>
    </ul>
  </div>
</div>

### HTML / CSS

```css
@import '@tdgs/core/components/search/search.css';
```

```html
<form class="tds-search" role="search" action="/rechercher" method="get">
  <label class="tds-search__label" for="service-search">Rechercher un service</label>
  <div class="tds-search__controls">
    <input
      id="service-search"
      class="tds-search__input"
      type="search"
      name="q"
      placeholder="Ex. carte nationale d'identité"
    />
    <button class="tds-search__submit" type="submit">Rechercher</button>
  </div>
</form>
```

<TabItem label="Accessibilité">

<Aside type="tip" title="Règles critiques">
  - Conserver un label associé au champ via `for` et `id`
  <br />
  - Utiliser `type="search"` et un bouton de soumission explicite
  <br />
  - Relier les indications et erreurs avec `aria-describedby`
  <br />
  - Annoncer les résultats dynamiques avec une zone `aria-live` adaptée
  <br />- Ne pas remplacer la recherche par un contrôle uniquement visuel
</Aside>
