<div class="tds-component-intro">
  <p class="tds-component-intro__eyebrow">Statut · Catégorie · Compteur</p>
  <p>
    Les badges mettent en évidence une information courte et immédiatement identifiable sans
    interrompre la lecture principale.
  </p>
</div>

<div class="tds-component-grid">
  <div class="tds-component-card">
    <strong>À utiliser pour</strong>
    <ul>
      <li>l'état d'un dossier ou d'une démarche ;</li>
      <li>une catégorie ou un type de contenu ;</li>
      <li>un compteur court associé à une section.</li>
    </ul>
  </div>
  <div class="tds-component-card">
    <strong>À éviter pour</strong>
    <p>
      Une action, une longue phrase ou une information qui dépendrait uniquement d'une couleur. Dans
      ces cas, utilisez respectivement un bouton, un texte descriptif ou un composant d'alerte.
    </p>
  </div>
</div>

<Aside type="note" title="Règle de contenu">
  Un badge doit rester court, lisible et utile au contexte. Le libellé porte toujours l'information
  : la couleur ne suffit jamais à elle seule.
</Aside>

```css

```

<span class="tds-badge tds-badge--warning">En attente</span>
<span class="tds-badge tds-badge--danger">Rejeté</span>

### Avec point de statut

```html
<span class="tds-badge tds-badge--success">
  <span class="tds-badge__dot" aria-hidden="true"></span>
  En ligne
</span>

<span class="tds-badge tds-badge--danger">
  <span class="tds-badge__dot" aria-hidden="true"></span>
  Hors ligne
</span>
```

### Forme rectangulaire

```html
<!-- Modificateur --square pour les catégories et tags -->
<span class="tds-badge tds-badge--info tds-badge--square">Document</span>
<span class="tds-badge tds-badge--default tds-badge--square">Formulaire</span>
```

<TabItem label="Accessibilité">

<Aside type="tip" title="Le badge ne doit jamais être la seule information">
  Le point de statut (`tds-badge__dot`) est décoratif (`aria-hidden="true"`) — le texte du badge
  porte toujours l'information. N'utilisez jamais une couleur seule (ex. un badge vide, juste
  coloré) pour communiquer un statut : ajoutez systématiquement un libellé texte.
</Aside>
