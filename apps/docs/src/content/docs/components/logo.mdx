<Tabs>
<TabItem label="Présentation">

`Logo` affiche la marque d'une institution (pictogramme + nom + sous-titre)
de façon cohérente. Le pictogramme est fourni par le contenu ; aucune
ressource DSFR n'est copiée.

</TabItem>
<TabItem label="Démo">

Rendu avec le CSS réellement livré par `@tdgs/core`. Le contenu de `tds-logo__mark`
(ici un glyphe de substitution) est fourni par le consommateur — SVG d'armoiries,
sceau ou monogramme.

<Preview title="Bloc de marque institutionnel" align="start" stack>
  <a class="tds-logo" href="#">
    <span class="tds-logo__mark" aria-hidden="true"><span style="font-weight:700">★</span></span>
    <span class="tds-logo__text">
      <span class="tds-logo__title">République du Tchad</span>
      <span class="tds-logo__subtitle">Portail des services publics</span>
    </span>
  </a>
</Preview>

[Ouvrir le terrain de jeu complet →](/playground/#logo)

</TabItem>
<TabItem label="Code">

```css
@import '@tdgs/core/components/logo/logo.css';
```

```html
<a class="tds-logo" href="/">
  <span class="tds-logo__mark" aria-hidden="true"><!-- pictogramme --></span>
  <span class="tds-logo__text">
    <span class="tds-logo__title">République du Tchad</span>
    <span class="tds-logo__subtitle">Portail des services publics</span>
  </span>
</a>
```

| Intégration | API                                                                      |
| ----------- | ------------------------------------------------------------------------ |
| React       | `<Logo href="/" mark={<span>★</span>} title="République du Tchad" subtitle="Portail des services publics" />` |
| Vue         | `<TdsLogo href="/" title="République du Tchad" subtitle="Portail des services publics" />` avec slot `mark` |

</TabItem>
<TabItem label="Accessibilité">

<Aside type="tip" title="Marque décorative">
  Le pictogramme est décoratif (`aria-hidden`) ; le nom de l'institution est
  le texte accessible du bloc. Sur fond sombre, utilisez la variante
  `tds-logo--on-dark`.
</Aside>

</TabItem>
</Tabs>
