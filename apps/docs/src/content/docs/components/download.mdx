<Tabs>
<TabItem label="Présentation">

`Download` signale clairement une ressource à télécharger et peut afficher son format, sa taille ou
une description. Il complète `Link` lorsque l'utilisateur doit comprendre la nature du fichier avant
de l'ouvrir.

</TabItem>
<TabItem label="Démo">

Rendu avec le CSS réellement livré par `@tdgs/core`.

</TabItem>
<TabItem label="Accessibilité">

<Aside type="tip" title="Destination compréhensible">
  Le libellé doit identifier le document ou l'action. Ajoutez le format et la taille lorsque cela
  aide à anticiper le téléchargement ; l'icône reste décorative.
</Aside>
