<TabItem label="Présentation">

`Quote` structure une citation, un témoignage ou une parole institutionnelle sans utiliser une image
ou une couleur comme seule information. Utilisez-le avec parcimonie dans les pages de contenu.

</TabItem>

</TabItem>
<TabItem label="Code">

```css
@import '@tdgs/core/components/quote/quote.css';
```

```html
<blockquote class="tds-quote">
  <p class="tds-quote__text">La citation doit rester compréhensible hors de son contexte visuel.</p>
  <footer class="tds-quote__footer">
    <span class="tds-quote__author">Nom de l'auteur</span>
    <cite class="tds-quote__source">Source publiée</cite>
  </footer>
</blockquote>
```

| Intégration | API                                                   |
| ----------- | ----------------------------------------------------- |
| React       | `<Quote author="Nom" source="Source">…</Quote>`       |
| Vue         | `<TdsQuote author="Nom" source="Source">…</TdsQuote>` |

</TabItem>
<TabItem label="Accessibilité">

<Aside type="tip" title="Sémantique native">
  Utilisez le HTML `<blockquote>` et `<cite>` fournis. L'auteur et la source doivent être lisibles,
  et la citation ne doit pas contenir de contenu interactif imbriqué sans nécessité.
</Aside>

</TabItem>
