<Tabs>
<TabItem label="Présentation">

`Range` permet de choisir une valeur dans un intervalle (min/max) à l'aide d'un
curseur. La valeur courante est affichée à côté du libellé. Le contrôle natif
`input[type=range]` reste utilisable au clavier sans JavaScript.

</TabItem>
<TabItem label="Démo">

Rendu avec le CSS réellement livré par `@tdgs/core`. La valeur affichée est mise à
jour par le script de référence (onglet Code).

<Preview title="Curseur de plage avec valeur" align="start" stack>

    <div class="tds-range__header">
      <label class="tds-range__label" for="demo-range">Budget mensuel (FCFA)</label>
      <span class="tds-range__value" aria-hidden="true">250 000</span>
    </div>
    <input id="demo-range" class="tds-range__input" type="range" min="0" max="1000" value="250" step="10" />
  </div>
</Preview>

[Ouvrir le terrain de jeu complet →](/playground/#range)

</TabItem>
<TabItem label="Code">

```css
@import '@tdgs/core/components/range/range.css';
```

```html
<div class="tds-range">
  <div class="tds-range__header">
    <label class="tds-range__label" for="budget">Budget mensuel</label>
    <span class="tds-range__value" aria-hidden="true">250 000 FCFA</span>
  </div>
  <input id="budget" class="tds-range__input" type="range" min="0" max="1000" value="250" step="10" />
</div>
```

| Intégration | API                                                                 |
| ----------- | ------------------------------------------------------------------- |
| React       | `<Range label="Budget" min={0} max={1000} defaultValue={250} />`    |
| Vue         | `<TdsRange v-model="budget" label="Budget" :min="0" :max="1000" />` |

</TabItem>
<TabItem label="Accessibilité">

<Aside type="tip" title="Valeur exposée">
  La valeur affichée est décorative (`aria-hidden`) ; c'est l'élément `range`
  natif qui porte le rôle `slider` et la valeur accessible. Les flèches du
  clavier restent actives.
</Aside>

</TabItem>
