---
title: Icon
description: Système d'icônes SVG indépendant, accessible et compatible avec les thèmes TDGS.
---

Les icônes TDGS sont des tracés SVG originaux et sobres, rendus avec `currentColor`. Elles
peuvent donc suivre automatiquement les thèmes clair, sombre et contraste élevé.

## Utilisation HTML

Importez la feuille d'icônes avec le socle TDGS, puis utilisez un SVG inline pour les pages
qui ne reposent pas sur React ou Vue :

```html
<svg class="tds-icon tds-icon--md" viewBox="0 0 24 24" aria-hidden="true" focusable="false">
  <path d="M5 12l4 4L19 6"></path>
</svg>
```

Une icône informative doit avoir un titre accessible :

```html
<svg class="tds-icon" viewBox="0 0 24 24" role="img" aria-labelledby="info-title">
  <title id="info-title">Informations</title>
  <path d="M12 16v-4M12 8h.01M21 12a9 9 0 1 1-18 0 9 9 0 0 1 18 0Z"></path>
</svg>
```

## React et Vue

Les bindings exposent un composant `Icon` commun aux deux frameworks :

```tsx
import { Icon } from '@tdgs/react';

<Icon name="check" size="sm" aria-label="Dossier validé" />;
```

```vue
<script setup lang="ts">
import { Icon } from '@tdgs/vue';
</script>

<Icon name="arrowRight" title="Continuer" />
```

Les noms disponibles sont `arrowRight`, `check`, `chevronDown`, `close`, `externalLink`, `info`,
`menu`, `minus`, `plus`, `search`, `upload` et `warning`.

## Accessibilité

- utilisez `aria-hidden="true"` pour une icône purement décorative ;
- utilisez `title`, `aria-label` ou `aria-labelledby` lorsqu'elle porte une information ;
- ne transmettez jamais une information uniquement par la couleur de l'icône ;
- les icônes d'action doivent rester dans un bouton ou un lien avec un nom accessible.
