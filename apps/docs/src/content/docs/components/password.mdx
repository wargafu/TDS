<Tabs>
<TabItem label="Présentation">

`Password` permet de saisir un mot de passe sans l'afficher, avec une bascule
« afficher / masquer » accessible au clavier et annoncée aux technologies
d'assistance. Il réutilise la structure et les états du système de formulaire.

</TabItem>
<TabItem label="Démo">

<iframe
  src="/playground/#password"
  title="Démo du composant Mot de passe"
  style="width:100%; height: 18rem; border: 1px solid var(--sl-color-gray-5); border-radius: 0.5rem;"
  loading="lazy"
></iframe>

</TabItem>
<TabItem label="Code">

```css
@import '@tdgs/core/components/password/password.css';
```

```html
<div class="tds-password">
  <label class="tds-field__label" for="pwd">Mot de passe</label>
  <div class="tds-password__control">
    <input class="tds-input" id="pwd" type="password" autocomplete="current-password" />
    <button type="button" class="tds-password__toggle" aria-label="Afficher le mot de passe">
      <span aria-hidden="true">👁</span>
    </button>
  </div>
</div>
```

| Intégration | API                                                                                     |
| ----------- | --------------------------------------------------------------------------------------- |
| React       | `<Password label="Mot de passe" required error="Le mot de passe est requis" />`         |
| Vue         | `<TdsPassword v-model="pwd" label="Mot de passe" required error="Le mot de passe est requis" />` |

</TabItem>
<TabItem label="Accessibilité">

<Aside type="tip" title="Révélation volontaire">
  La bascule porte un `aria-label` et `aria-pressed`. Ne changez jamais le `type`
  d'un mot de passe sans action explicite de l'utilisateur, et ne fournissez pas
  de bouton « générer » avec un libellé vide.
</Aside>

</TabItem>
