<TabItem label="Présentation">

Progression expose le rôle ARIA `progressbar`. Une valeur connue permet d'indiquer un avancement
mesurable ; sans valeur, la variante indéterminée signale qu'un traitement est en cours sans
prédire sa durée.

## Choisir la bonne variante

| Variante     | Utilisation                                     | Information obligatoire                           |
| ------------ | ----------------------------------------------- | ------------------------------------------------- |
| Déterminée   | Téléversement, traitement ou démarche mesurable | `aria-valuemin`, `aria-valuemax`, `aria-valuenow` |
| Indéterminée | Chargement dont la durée est inconnue           | Un nom accessible, sans valeur numérique inventée |

### HTML / CSS

```css
@import '@tdgs/core/components/progress/progress.css';
```

```html
<div class="tds-progress">
  <div class="tds-progress__label" id="upload-progress-label">
    <span>Envoi des justificatifs</span>
    <span aria-hidden="true">40 %</span>
  </div>
  <div
    class="tds-progress__track"
    role="progressbar"
    aria-labelledby="upload-progress-label"
    aria-valuemin="0"
    aria-valuemax="100"
    aria-valuenow="40"
  >
    <div class="tds-progress__indicator" style="--tds-progress-value: 40%"></div>
  </div>
</div>
```

<TabItem label="Accessibilité">

<Aside type="tip" title="Règles critiques">
  - Fournir un nom accessible avec `aria-label` ou `aria-labelledby`
  <br />
  - Renseigner les valeurs ARIA quand l'avancement est connu
  <br />
  - Ne pas utiliser une animation comme seule information
  <br />
  - Respecter `prefers-reduced-motion`
  <br />- Annoncer les changements importants dans une zone `aria-live` distincte si nécessaire
</Aside>
