---
title: Intégrations
description: Utiliser TDGS avec HTML pur, React ou Vue.
---


TDGS est **CSS-first et sans dépendance runtime** : `@tdgs/core` fonctionne partout,
sans framework. Pour les équipes qui utilisent React ou Vue, des bindings dédiés
exposent chaque composant comme un composant typé, sans jamais dupliquer le CSS source.
