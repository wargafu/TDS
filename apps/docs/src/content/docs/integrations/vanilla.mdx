`@tdgs/core` est utilisable tel quel dans n'importe quel projet HTML/CSS, quel
que soit le framework de rendu côté serveur (PHP, Django, Rails, CMS, intranet…).
Aucune dépendance JavaScript n'est requise pour les composants statiques
(Button, Card, Alert, Badge, Table, Header, Footer, Accordion…).

```css
@import "@tdgs/core/tokens/color.css";
@import "@tdgs/core/tokens/typography.css";
@import "@tdgs/core/tokens/spacing.css";
@import "@tdgs/core/components/button/button.css";
```

```html
<button type="button" class="tds-button tds-button--primary tds-button--md">
  Soumettre la demande
</button>
```

Deux composants ont un comportement interactif qui nécessite un peu de JavaScript
natif (documenté directement sur leur page) : **Modal** (`<dialog>.showModal()`) et
**Tabs** (roving tabindex WAI-ARIA). Tous les autres composants — y compris
Accordion — fonctionnent sans JavaScript.
