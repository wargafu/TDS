`@tdgs/core` est préparé pour npm, mais sa publication publique n'a pas encore été effectuée.
Le guide décrit la cible d'installation ainsi que l'utilisation dans le monorepo.

<Aside type="caution" title="Avant la publication npm">
  Pour travailler depuis les sources, clonez le dépôt puis lancez `pnpm install` à la racine. Les
  commandes npm, pnpm et yarn ci-dessous deviennent utilisables dès que le package est publié.
</Aside>

  "module"`).

## Importer les tokens CSS

La manière la plus simple est d'importer les CSS custom properties directement.
Elles sont disponibles pour chaque système de tokens.

```css
/* Importer tous les tokens (recommandé pour démarrer) */
@import '@tdgs/core/tokens/color.css';
@import '@tdgs/core/tokens/typography.css';
@import '@tdgs/core/tokens/spacing.css';
@import '@tdgs/core/tokens/radius.css';
@import '@tdgs/core/tokens/shadow.css';
@import '@tdgs/core/tokens/motion.css';
@import '@tdgs/core/tokens/z-index.css';
```

Après import, toutes les variables CSS `--tds-*` sont disponibles globalement.

```css
/* Utilisation directe */
.mon-composant {
  color: var(--tds-color-blue-500);
  padding: var(--tds-spacing-4);
  border-radius: var(--tds-radius-sm);
}
```

---

## Importer les styles composants

Importez les CSS des composants que vous utilisez.

```css
/* Bouton */
@import '@tdgs/core/components/button/button.css';

/* Champs de formulaire */
@import '@tdgs/core/components/input/input.css';
```

## Importer les tokens TypeScript

Pour accéder aux valeurs de tokens dans votre code TypeScript/JavaScript :

```typescript
// Importer les tokens individuellement
import { color } from '@tdgs/core/tokens';
import { typography } from '@tdgs/core/tokens';
import { spacing } from '@tdgs/core/tokens';

// Ou tout importer depuis la racine
import { color, typography, spacing, radius, shadow, motion } from '@tdgs/core';

// Utiliser les tokens
const primaryBlue = color.blue[500]; // '#0B3A82'
const bodySize = typography.sizes.md; // '1rem'
const gap = spacing.scale[4]; // '1rem' (16px)
```

---

## Importer les types TypeScript

```typescript
import type { ColorTokens } from '@tdgs/core/tokens';
import type { ButtonVariant, ButtonSize } from '@tdgs/core/components/button';
import type { InputVariant, InputSize, InputState } from '@tdgs/core/components/input';
```

## Import JSON (Style Dictionary / Figma)

Les tokens sont aussi disponibles en JSON pour l'intégration avec Style Dictionary,
les plugins Figma ou d'autres outils de design.

```javascript
import colorJson from '@tdgs/core/tokens/color.json' assert { type: 'json' };
// ou en CommonJS
const colorJson = require('@tdgs/core/tokens/color.json');
```

## Installation sans bundler (CDN / HTML pur)

Pour utiliser TDGS sans outil de build, copiez les fichiers CSS dans votre projet
ou pointez vers un CDN auto-hébergé.

```html
<!doctype html>
<html lang="fr">
  <head>
    <!-- Polices institutionnelles -->
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link
      href="https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@300;400;500;600;700;800&display=swap"
      rel="stylesheet"
    />

    <!-- Tokens TDGS (depuis votre serveur) -->
    <link rel="stylesheet" href="/assets/tds/tokens/color.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/typography.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/spacing.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/radius.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/shadow.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/motion.css" />
    <link rel="stylesheet" href="/assets/tds/tokens/z-index.css" />

    <!-- Composants TDGS -->
    <link rel="stylesheet" href="/assets/tds/components/button/button.css" />
    <link rel="stylesheet" href="/assets/tds/components/input/input.css" />
  </head>
</html>
```

<Aside type="tip" title="Self-hosting des polices">
  En production, hébergez les fichiers WOFF2 de **Source Sans 3** et **Noto Naskh Arabic** sur vos
  propres serveurs. Cela évite les requêtes vers Google Fonts et garantit la disponibilité en
  environnements réseau restreints (intranet gouvernemental).
</Aside>

## Vérification de l'installation

Après installation, vérifiez que les tokens CSS sont bien chargés dans le navigateur :

```javascript
// Dans la console du navigateur
getComputedStyle(document.documentElement).getPropertyValue('--tds-color-blue-500');
// Doit retourner : ' #0B3A82'
```
