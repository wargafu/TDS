TDGS est un projet open source indépendant. Cette déclaration décrit l'état connu des contrôles
accessibilité de sa documentation et ne constitue pas une déclaration institutionnelle au nom de
la République du Tchad.

Cette déclaration s'applique au site de documentation publié depuis le dépôt
**github.com/kisaigo/TDGS**. Toute URL miroir doit être vérifiée séparément.

---

## État de conformité

<Aside type="caution" title="Non conforme">
  Ce site est **non conforme** avec le RGAA. Aucun audit d'accessibilité complet (manuel, avec tests
  utilisateurs et technologies d'assistance réelles) n'a été mené à ce jour. Nous ne publions pas de
  taux de conformité tant qu'un audit réel n'a pas été réalisé — afficher un chiffre non vérifié
  serait trompeur.
</Aside>

Ce qui est fait aujourd'hui :

- Les composants TDGS sont conçus selon une cible WCAG 2.2 AA (voir
  [Principes WCAG](/fondamentaux/wcag/))
- Un script de vérification automatisée axe-core est intégré au pipeline du terrain de jeu ; son
  résultat doit être rejoué et consigné à chaque release
- Contraste, structure de titres, labels de formulaire et navigation clavier de base font l'objet
  de contrôles ciblés

Ce qui reste à faire (voir la [roadmap](/communaute/roadmap/)) :

- Audit WCAG 2.2 AA complet mené par un auditeur indépendant
- Tests avec de vrais utilisateurs de technologies d'assistance (lecteurs d'écran, navigation
  clavier exclusive, zoom, contraste élevé)
- Publication d'un taux de conformité et d'un plan d'action correctif

---

## Établissement de cette déclaration

Cette déclaration a été établie le 2 juillet 2026 sur la base d'une auto-évaluation partielle
(vérifications automatisées uniquement — pas d'audit manuel).

---

## Signaler un problème d'accessibilité

Si vous rencontrez un obstacle à l'accessibilité sur ce site, merci de le signaler via
[une issue GitHub](https://github.com/kisaigo/TDGS/issues) en décrivant le problème rencontré
et, si possible, la technologie d'assistance utilisée.
