## Éditeur du site

Ce site de documentation est maintenu par la communauté de contributeurs du projet open source
TDGS (Tchad Design System), hébergé sur le dépôt public
[github.com/kisaigo/TDGS](https://github.com/kisaigo/TDGS).

## Hébergement

Ce site est hébergé par **GitHub Pages** (GitHub, Inc. — 88 Colin P Kelly Jr St, San Francisco,
CA 94107, États-Unis).

## Propriété intellectuelle

Le code source de TDGS (packages, tokens, composants) est publié sous licence
[MIT](https://github.com/kisaigo/TDGS/blob/main/LICENSE) — libre de réutilisation, y compris à
des fins commerciales, sans obligation d'attribution.

Le contenu éditorial de cette documentation (textes, exemples, illustrations) est publié dans
le même esprit d'ouverture ; contactez les mainteneurs via
[GitHub](https://github.com/kisaigo/TDGS/discussions) pour toute question de réutilisation.

## Contact

Pour toute question relative à ce site, ouvrez une
[issue GitHub](https://github.com/kisaigo/TDGS/issues) ou une
[discussion](https://github.com/kisaigo/TDGS/discussions).
