# Template tableau de bord administratif

Point de départ statique pour un espace de suivi : navigation latérale, indicateurs, tableau de
données et états métier. Les données affichées sont fictives et doivent être remplacées par des
données autorisées et correctement protégées.

Les imports CSS suivent la même convention que le template portail citoyen. Le template ne
constitue pas une spécification de sécurité ou de gestion des habilitations.
