# Template portail citoyen

Point de départ statique pour un portail de services publics. Le template illustre une page
d'accueil, la recherche, les démarches populaires, une actualité et les liens d'accès rapide.

## Utilisation

Depuis une copie du dépôt, servez la racine avec un serveur statique afin de conserver les
imports relatifs vers `packages/core/src/tdgs.css`. Pour une application, remplacez cet import
par `@tdgs/core/tdgs.css` après publication du package.

Le contenu, les logos institutionnels et les liens doivent être validés par l'administration
concernée avant toute mise en production.
